# Trilha-Python-Checkpoint-04

Trilha Python - Curso Presencial Senac Tech - Atividade

Projeto desenvolvido durante a Trilha de Python com o objetivo de praticar organização de
código, banco de dados e desenvolvimento de aplicações desktop utilizando Python.

A proposta do sistema é aplicar conceitos vistos em aula de uma forma prática, criando 
uma aplicação estruturada e funcional.

Tecnologias utilizadas

Python 3
SQLite3
Tkinter
Git & GitHub

Estrutura do projeto
```
Trilha-Python-Checkpoint-04/
│
├── controllers/
├── models/
├── views/
├── assets/
│
├── inventario.db
├── main.py
└── README.md
```
Funcionalidades

Sistema de login
Cadastro de itens
Persistência de dados com SQLite
Interface gráfica desktop
Organização em padrão MVC

O que foi praticado neste projeto

Durante o desenvolvimento foram trabalhados conceitos importantes como:

Programação orientada a objetos
Modularização
CRUD
Manipulação de banco de dados
Organização de aplicações Python
Separação de responsabilidades utilizando MVC

Sobre o projeto

Esse projeto foi desenvolvido como atividade acadêmica/prática da trilha de Python e
serviu como uma oportunidade para consolidar conhecimentos vistos durante o curso.

Além da parte técnica, também foi importante para praticar organização de projeto, 
versionamento com Git e estruturação de aplicações maiores.
